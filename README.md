# CreateClass_108

program python sederhana bwt bikin class PersegiPanjang sekalian itung luas sm keliling nya

### Penjelasan Kodingan
- __init__(self, panjang, lebar): konstruktor bwt nentuin niali panjang sm lebar pas objeknya dibkin
- hitung_keliling(): rumus ngitung keliling persegi pnjng 2 * (panjang + lebar)
- hitung_luas(): rumus itung luasnya panjang * lebar
- __str__(): biar pas di print objeknya langsung kluar format tulisan ukuran pnjng sm lebarnya

### Output Program
contoh pake nilai panjang 3 cm dan lebar 2 cm:
```text
persegi panjang, panjang 3 cm, dan lebar 2 cm
Keliling : 10 cm
Luas     : 6 cm2
```
